# Personal Budget Tracker (Week 3)

A responsive HTML and CSS budget tracker interface featuring a structured expense form, a formatted expense history table, collapsible usage instructions, and an embedded budgeting video.

## What Each File Does

- **`index.html`**: Defines the page layout and content structure, including the header banner, `<details>` instructions block, expense entry `<form>` with category `<select>` options, expense history `<table>`, and embedded YouTube `<iframe>`.
- **`style.css`**: Applies the color palette via CSS variables (`:root`), loads Google Fonts (`Plus Jakarta Sans` and `Inter`), styles the form and table, and uses `margin`, `padding`, `border`, and `border-radius` to separate sections cleanly.
- **`README.md`**: Documents the project overview, file responsibilities, and styling choices.

## Week 3 Rubric Highlights

- **Intentional Color Palette**: Uses a cohesive slate-navy (`#1E293B`), emerald green (`#16A34A`), sky-blue focus/info highlights (`#0284C7` / `#E0F2FE`), and soft light-gray surfaces (`#F8FAFC` / `#F1F5F9`).
- **Typography**: Pairs `Plus Jakarta Sans` for headings and buttons with `Inter` for body copy, form fields, and `tabular-nums` for aligned currency amounts.
- **Table & Form Styling**: Styles table headers, cell padding, collapsed borders, alternating `nth-child(even)` rows, row hover states, focused form inputs, and an emerald action button.
- **CSS Box Model**: Uses consistent `margin`, `padding`, `border`, and `border-radius` across cards, form groups, and table containers.
